# AI Fluency OS

AI Fluency OS is a local-first, evidence-driven learning system for developing
senior software-engineering fluency with AI.

## Current status

Planning and initial assessment. The roadmap is a draft pending approval; no
application harness or learning mission has been implemented yet.

## Start here

- [12-week roadmap](docs/12-week-roadmap.md)
- [Initial capability assessment](docs/initial-capability-assessment.md)

## Working principles

- Progress is demonstrated through evaluated engineering artifacts.
- Courses support practical missions; course completion is not evidence of
  proficiency.
- AI output is treated as a hypothesis until verified.
- Reusable workflows become registered skills only after approval and testing
  on a second meaningful case.
- Knowledge and skills remain portable and model-independent.
- Destructive or externally visible actions require explicit approval.
